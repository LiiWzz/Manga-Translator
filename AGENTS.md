# Agent instructions

- This is an English-to-Thai manga Chrome extension POC.
- Use feature branches and PRs; never merge automatically.
- Keep secrets out of browser code, git, logs and fixtures.
- Do not circumvent paywalls, anti-bot protections or copyright restrictions.
- API defaults to mock translator to make tests deterministic.
- Add tests for each bugfix and run API tests and JS syntax checks before proposing merge.
- Keep Chrome permissions minimal. Do not broaden origin permissions without human review.
- Prioritize translation quality, overlay geometry, image-fetch constraints, performance and cost.
