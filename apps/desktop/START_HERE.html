เริ่มใช้ Manga Thai Reader

ชุดทดลองสำหรับเพื่อน · ไม่ต้องติดตั้ง Python หรือ Docker · ใช้ Chrome บนคอมพิวเตอร์

  1. แตก ZIP ก่อน แล้วเก็บแอปไว้ในเครื่อง
    Windows: เปิด MangaThaiReader/MangaThaiReader.exe โดยเก็บทั้งโฟลเดอร์ไว้ด้วยกัน
    macOS: ย้าย MangaThaiReader.app ไป Applications แล้วเปิดแอป
  2. ในแอป กด เปิดโฟลเดอร์ extension จากนั้นใน Chrome เปิด chrome://extensions เปิด Developer mode → Load unpacked → เลือกโฟลเดอร์ extension ที่แอปเปิดให้
  3. เปิด Options ของส่วนขยาย สร้างรหัสจับคู่ในแอป คัดลอกไปกรอกและยืนยันสิทธิ์ รหัสใช้ได้ครั้งเดียวภายใน 10 นาที ไม่ต้องส่งรหัสให้คนอื่น และไม่ต้องจับคู่ใหม่ทุกครั้ง
  4. แอปเริ่มใน โหมดทดลอง ซึ่งแสดงข้อความตัวอย่างและไม่อ่านภาพจริง หากต้องการแปลจริง กดหยุดระบบ เลือก ใช้ ChatGPT แล้วกดเริ่ม จาก Options กด จัดการการเชื่อมต่อ เข้าสู่บัญชีของตัวเอง ตรวจการอนุญาต และเลือกโมเดลที่รองรับภาพ
  5. เปิดแท็บมังงะที่มีสิทธิ์ใช้งาน กดไอคอน extension เปิด Reader แล้วกด แปลภาพที่เห็น

ครั้งต่อไป: เปิดแอปแล้วใช้ extension ได้เลย แอปจำโหมดที่เลือกไว้ เปิดหน้าต่างแอปค้างไว้ระหว่างอ่าน เมื่อปิดหน้าต่าง ระบบแปลจะหยุด ไม่มีการติดตั้งบริการที่เปิดตามเครื่องอัตโนมัติ

บัญชีเก็บอยู่ในเครื่องของคุณ คำแปลเก็บใน Chrome ภาพที่สั่งแปลจะส่งไปยังผู้ให้บริการในโหมด ChatGPT การแปลอาจใช้โควตาบัญชี และสิทธิ์บัญชีหรือโมเดลอาจไม่รองรับการใช้งานนี้

แอปรุ่นทดลองนี้ยังไม่ได้ลงนามสำหรับเผยแพร่ทั่วไป หากระบบปฏิบัติการบล็อกการเปิด ให้ติดต่อผู้ส่งเพื่อขอรุ่นที่ลงนาม ไม่ควรปิดระบบป้องกันของเครื่อง

หากเปิดระบบไม่ได้: ปิดแอปที่เปิดซ้ำหรือ backend Docker เดิมแล้วลองใหม่ ชุดนี้รองรับ Reader แบบ Vision ส่วน overlay/OCR รุ่นเก่าต้องติดตั้งส่วนประกอบแยก

เมื่ออัปเดต: ปิดแอปเดิม เปิดแอปใหม่ กดเปิดโฟลเดอร์ extension เพื่ออัปเดตไฟล์ แล้วกด Reload ในหน้า extensions อย่าลบข้อมูลบัญชีหรือคำแปลเพื่ออัปเดต
